# 类型收窄与类型断言

## JS 中已有的运行时判断

`typeof`、`instanceof`、`in` 和条件判断都是 JavaScript 本身已有的运行时能力。TypeScript 会利用这些判断结果，在对应代码分支里自动缩小变量类型。

```js
function print(value) {
  if (typeof value === "string") {
    console.log(value.toUpperCase());
  }
}

if ("localStorage" in window) {
  console.log("支持 localStorage");
}
```

在 TypeScript 中，同样的判断会带来类型收窄：

```ts
function print(value: string | number) {
  if (typeof value === "string") {
    console.log(value.toUpperCase());
  } else {
    console.log(value.toFixed(2));
  }
}
```

## 1. 类型收窄是什么

类型收窄是 TypeScript 根据代码控制流，把一个宽类型缩小为更具体类型的过程。

```ts
function print(value: string | number) {
  if (typeof value === "string") {
    console.log(value.toUpperCase());
  } else {
    console.log(value.toFixed(2));
  }
}
```

进入 `if` 分支后，`value` 从 `string | number` 收窄成 `string`。

## 2. typeof 收窄

`typeof` 常用于判断原始类型：

```ts
function format(value: string | number | boolean) {
  if (typeof value === "string") {
    return value.trim();
  }

  if (typeof value === "number") {
    return value.toFixed(2);
  }

  return value ? "yes" : "no";
}
```

注意 `typeof null` 的结果是 `"object"`，所以判断对象时要先排除 `null`：

```ts
function fn(value: object | null) {
  if (value !== null) {
    console.log(value);
  }
}
```

## 3. truthiness 收窄

可以通过真假值判断排除 `null`、`undefined`、空字符串等：

```ts
function printLength(value?: string) {
  if (value) {
    console.log(value.length);
  }
}
```

但要小心：空字符串 `""` 也会被排除。如果业务上空字符串是合法值，应写更精确的判断：

```ts
function printLength(value?: string) {
  if (value !== undefined) {
    console.log(value.length);
  }
}
```

## 4. in 操作符收窄

```ts
type Fish = {
  swim: () => void;
};

type Dog = {
  bark: () => void;
};

function move(animal: Fish | Dog) {
  if ("bark" in animal) {
    animal.bark();
  } else {
    animal.swim();
  }
}
```

`in` 适合判断对象是否具有某个属性。

## 5. instanceof 收窄

```ts
function printDate(value: Date | string) {
  if (value instanceof Date) {
    console.log(value.toISOString());
  } else {
    console.log(value);
  }
}
```

`instanceof` 依赖运行时构造函数，适合类实例、内置对象。

## 6. 判别联合

给联合类型的每个成员加一个共同字面量属性，可以形成判别联合：

```ts
type Circle = {
  kind: "circle";
  radius: number;
};

type Square = {
  kind: "square";
  size: number;
};

type Shape = Circle | Square;

function area(shape: Shape) {
  switch (shape.kind) {
    case "circle":
      return Math.PI * shape.radius ** 2;
    case "square":
      return shape.size ** 2;
  }
}
```

这是业务建模中非常推荐的写法。

## 7. 类型谓词

自定义判断函数可以返回类型谓词：

```ts
type Fish = {
  swim: () => void;
};

type Dog = {
  bark: () => void;
};

function isDog(value: Fish | Dog): value is Dog {
  return "bark" in value;
}

function move(animal: Fish | Dog) {
  if (isDog(animal)) {
    animal.bark();
  } else {
    animal.swim();
  }
}
```

`value is Dog` 告诉 TypeScript：如果函数返回 `true`，传入的 `value` 就是 `Dog`。

## 8. 类型断言

类型断言用于告诉 TypeScript：“我比你更清楚这个值的类型”。

```ts
const input = document.getElementById("myInput") as HTMLInputElement;
input.value;
```

另一种尖括号写法：

```ts
const input = <HTMLInputElement>document.getElementById("myInput");
```

在 `.tsx` 中尖括号容易和 JSX 冲突，所以更推荐 `as`。

类型断言不是类型转换：

```ts
let value: any = "hello";
let n = value as number;

console.log(typeof n); // "string"
// n.toFixed(); // 运行时报错
```

## 9. 非空断言

`!` 表示你确定一个值不是 `null` 或 `undefined`：

```ts
const el = document.getElementById("root")!;
el.innerHTML = "hello";
```

它会跳过空值检查，使用时要谨慎。更安全的写法是显式判断：

```ts
const el = document.getElementById("root");

if (el) {
  el.innerHTML = "hello";
}
```

## 10. as const

`as const` 会让字面量保持最窄类型，并把对象属性变成只读：

```ts
const routes = {
  home: "/",
  user: "/user"
} as const;

type RouteName = keyof typeof routes; // "home" | "user"
type RoutePath = (typeof routes)[RouteName]; // "/" | "/user"
```

## 11. satisfies

`satisfies` 用来检查一个表达式是否满足某个类型，同时保留表达式自身推断出的精确类型：

```ts
type RouteConfig = Record<string, { path: string }>;

const routes = {
  home: { path: "/" },
  user: { path: "/user" }
} satisfies RouteConfig;

type RouteName = keyof typeof routes; // "home" | "user"
```

如果直接写类型注解：

```ts
const routes2: RouteConfig = {
  home: { path: "/" },
  user: { path: "/user" }
};

type RouteName2 = keyof typeof routes2; // string
```

`satisfies` 适合配置对象。
