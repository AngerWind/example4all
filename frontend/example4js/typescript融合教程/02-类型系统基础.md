# 类型系统基础

## 1. 类型注解和类型推断

类型注解是显式告诉 TypeScript 某个变量、参数或返回值的类型：

```ts
let age: number = 18;
let userName: string = "jack";
let isLoading: boolean = false;

function sum(a: number, b: number): number {
  return a + b;
}
```

如果声明和赋值同时出现，很多时候可以省略类型注解，让 TypeScript 自动推断：

```ts
let age = 18; // number
const title = "TypeScript"; // "TypeScript"
```

不要为了写类型而写类型。下面这种写法没有必要：

```ts
let count: number = 1;
```

可以直接写成：

```ts
let count = 1;
```

但函数参数通常应该显式标注，因为 TypeScript 很难从函数声明本身推断参数类型。

## 2. 原始类型

常见原始类型：

```ts
let n: number = 1;
let s: string = "hello";
let b: boolean = true;
let u: undefined = undefined;
let empty: null = null;
let sym: symbol = Symbol("id");
let big: bigint = 100n;
```

`number` 包含整数、浮点数、十六进制、二进制、八进制等数字：

```ts
let decimal: number = 6;
let hex: number = 0xf00d;
let binary: number = 0b1010;
let octal: number = 0o744;
```

## 3. 字面量类型

字面量类型表示“值只能是某个具体字面量”：

```ts
let direction: "up" | "down" | "left" | "right";

direction = "left";
// direction = "top"; // 报错
```

`const` 声明的基础类型值通常会被推断成更窄的字面量类型：

```ts
const str = "hello"; // 类型是 "hello"
let str2 = "hello"; // 类型是 string
```

对象字面量默认不会把每个属性都推断成只读字面量，因为对象属性仍可被修改：

```ts
const config = {
  method: "GET"
};

// config.method 的类型是 string，不是 "GET"
```

如果希望对象整体保持字面量和只读效果，可以用 `as const`：

```ts
const config = {
  method: "GET",
  timeout: 3000
} as const;

// config.method: "GET"
// config.timeout: 3000
```

## 4. 联合类型

联合类型表示一个值可以是多个类型之一：

```ts
let id: string | number;

id = "u_001";
id = 1001;
```

数组和联合类型组合时要注意括号：

```ts
let arr1: (number | string)[] = [1, "a", 2];

let arr2: number | string[];
arr2 = 123;
arr2 = ["a", "b"];
```

`(number | string)[]` 表示数组元素可以是数字或字符串。  
`number | string[]` 表示变量本身可以是数字，也可以是字符串数组。

## 5. any

`any` 表示任意类型。它会关闭 TypeScript 对该值的大部分检查：

```ts
let value: any = 1;
value = "hello";
value = true;

value.notExists();
const n: number = value;
```

没有类型注解且无法推断时，变量可能变成隐式 `any`：

```ts
let value; // any
```

真实项目中应尽量少用 `any`。如果暂时不知道类型，优先使用 `unknown`。

## 6. unknown

`unknown` 是类型安全的任意类型。它可以接收任何值，但不能在未检查前随便使用：

```ts
let value: unknown = "hello";

// value.length; // 报错

if (typeof value === "string") {
  console.log(value.length);
}
```

如果你确实确定它是某个类型，可以用类型断言：

```ts
const len = (value as string).length;
```

`unknown` 适合描述外部输入，例如接口返回值、`JSON.parse` 的结果、消息队列数据等。

## 7. void

`void` 常用于函数返回值，表示函数没有有意义的返回值：

```ts
function log(message: string): void {
  console.log(message);
}
```

在开启 `strictNullChecks` 时，`void` 函数可以返回 `undefined` 或不写 `return`，但不能返回 `null`：

```ts
function fn(): void {
  return undefined;
}
```

教程中“`void` 可以返回 `null`”的说法需要加前提：只有关闭 `strictNullChecks` 时才可能成立。现代项目建议开启 `strict`，所以应按不能返回 `null` 来理解。

## 8. never

`never` 表示永远不会出现的值。常见场景：

```ts
function fail(message: string): never {
  throw new Error(message);
}

function loopForever(): never {
  while (true) {}
}
```

`never` 也常用于穷尽检查：

```ts
type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "square"; size: number };

function area(shape: Shape): number {
  switch (shape.kind) {
    case "circle":
      return Math.PI * shape.radius ** 2;
    case "square":
      return shape.size ** 2;
    default: {
      const neverValue: never = shape;
      return neverValue;
    }
  }
}
```

如果以后给 `Shape` 新增一种类型，但忘记处理，`neverValue` 处会报错。

## 9. object、Object 和 {}

`object` 表示非原始类型：

```ts
let value: object;

value = {};
value = [];
value = () => {};
// value = 1; // 报错
```

但 `object` 太宽泛，实际开发中更常写具体对象结构：

```ts
let user: { name: string; age?: number };

user = { name: "jack" };
user = { name: "jack", age: 18 };
```

`Object` 和 `{}` 在 TypeScript 中含义容易误解，初学阶段不建议拿它们描述普通业务对象。
