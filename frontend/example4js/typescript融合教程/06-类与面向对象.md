# 类与面向对象

## JS 中已有的 class 能力

`class` 是 JavaScript 本身就有的语法，不是 TypeScript 独有。JS 已经支持 `class`、`constructor`、实例方法、静态方法、`extends`、`super`、getter/setter，以及 `#private` 运行时私有字段。

```js
class Animal {
  constructor(name) {
    this.name = name;
  }

  run() {
    console.log(`${this.name} 在跑`);
  }

  static create(name) {
    return new Animal(name);
  }
}

class Dog extends Animal {
  bark() {
    console.log("汪汪");
  }
}

const dog = new Dog("旺财");
dog.run();
dog.bark();
```

TypeScript 在 JS `class` 基础上增加类型能力：属性类型、构造函数参数类型、`public`、`protected`、`private`、`readonly`、`abstract`、`implements` 和 `override`。

```ts
abstract class Animal {
  constructor(public name: string) {}

  abstract run(): void;
}

class Dog extends Animal {
  override run() {
    console.log(`${this.name} 在跑`);
  }
}
```

## 1. 类的基本写法

TypeScript 的类建立在 JavaScript `class` 语法上，额外添加属性类型、访问修饰符、抽象类等类型能力。

```ts
class Person {
  name: string;
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }

  sayHello() {
    console.log(`大家好，我是${this.name}`);
  }
}

const p = new Person("孙悟空", 18);
p.sayHello();
```

如果属性有初始值，TypeScript 可以推断类型：

```ts
class Person {
  age = 18;
  gender = "男";
}
```

## 2. strictPropertyInitialization

开启 `strict` 后，类属性要么在声明时初始化，要么在构造函数中赋值：

```ts
class User {
  name: string;

  constructor(name: string) {
    this.name = name;
  }
}
```

如果属性确实会在框架或其他流程中赋值，可以使用 definite assignment assertion：

```ts
class User {
  name!: string;
}
```

不要滥用 `!`，它会绕开初始化检查。

## 3. 构造函数参数属性

TypeScript 支持在构造函数参数上直接声明属性：

```ts
class User {
  constructor(
    public name: string,
    private secret: string,
    protected id: number,
    readonly key: string
  ) {}
}
```

等价于先声明属性，再在构造函数中赋值。

## 4. public、protected、private

`public`：任何地方都能访问，默认就是 `public`。

```ts
class User {
  public name = "jack";
}

const user = new User();
console.log(user.name);
```

`protected`：类内部和子类内部能访问，实例外部不能访问。

```ts
class Animal {
  protected move() {
    console.log("move");
  }
}

class Dog extends Animal {
  run() {
    this.move();
  }
}
```

`private`：只有当前类内部能访问，子类和实例外部都不能访问。

```ts
class User {
  private secret = "secret";

  getSecret() {
    return this.secret;
  }
}
```

## 5. TS private 和 JS #private

TypeScript 的 `private` 主要是类型系统限制，编译到旧版本 JavaScript 后可能仍是普通属性。JavaScript 的 `#secret` 是运行时私有字段：

```ts
class User {
  #secret = "secret";

  getSecret() {
    return this.#secret;
  }
}
```

如果需要运行时真正私有，优先考虑 `#private`。如果只是做 TypeScript 类型层面的访问限制，`private` 更常见。

## 6. readonly

`readonly` 用来限制属性重新赋值：

```ts
class Person {
  readonly age: number;

  constructor(age: number) {
    this.age = age;
  }
}

const p = new Person(18);
// p.age = 20; // 报错
```

`readonly` 可以和访问修饰符组合：

```ts
class User {
  public readonly id: string;

  constructor(id: string) {
    this.id = id;
  }
}
```

## 7. getter 和 setter

访问器是 JavaScript 语法，TypeScript 在其基础上添加类型检查：

```ts
class Person {
  private _age: number;

  constructor(age: number) {
    this._age = age;
  }

  get age() {
    return this._age;
  }

  set age(value: number) {
    if (value >= 0) {
      this._age = value;
    }
  }
}

const person = new Person(18);
person.age = 20;
console.log(person.age);
```

## 8. 静态成员

静态成员属于类本身，不属于实例：

```ts
class Tools {
  static PI = 3.1415926;

  static sum(a: number, b: number) {
    return a + b;
  }
}

Tools.PI;
Tools.sum(1, 2);
```

## 9. 继承和 super

```ts
class Animal {
  constructor(public name: string) {}

  run() {
    console.log(`${this.name} 在跑`);
  }
}

class Dog extends Animal {
  constructor(name: string, public age: number) {
    super(name);
  }

  bark() {
    console.log("汪汪");
  }
}
```

子类构造函数中必须先调用 `super()`，再使用 `this`。

## 10. 方法重写和 override

子类可以重写父类方法：

```ts
class Animal {
  run() {
    console.log("animal run");
  }
}

class Dog extends Animal {
  override run() {
    console.log("dog run");
  }
}
```

建议开启 `noImplicitOverride`，这样重写父类方法时必须写 `override`，能避免父类方法改名后子类悄悄失效。

## 11. 抽象类

抽象类不能直接实例化，只能被继承：

```ts
abstract class Animal {
  abstract run(): void;

  sleep() {
    console.log("sleep");
  }
}

class Dog extends Animal {
  run() {
    console.log("dog run");
  }
}
```

抽象方法没有方法体，子类必须实现。

## 12. 类实现接口

```ts
interface Singable {
  name: string;
  sing(): void;
}

class Person implements Singable {
  name = "jack";

  sing() {
    console.log("sing");
  }
}
```

接口只检查实例侧结构，不检查类的静态侧成员。

## 13. 类型兼容性

TypeScript 采用结构类型系统。两个类只要实例结构兼容，就可以互相赋值：

```ts
class Point {
  x!: number;
  y!: number;
}

class Point2D {
  x!: number;
  y!: number;
}

const p: Point = new Point2D();
```

但如果类包含 `private` 或 `protected` 成员，兼容性会更严格，通常要求这些私有/受保护成员来自同一个声明。
