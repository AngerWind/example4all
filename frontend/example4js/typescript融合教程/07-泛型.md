# 泛型

## 1. 泛型解决什么问题

泛型用于描述“类型之间的关系”。当函数、接口、类在定义时不知道具体类型，但又需要保留输入和输出之间的类型关系时，就应该使用泛型。

不推荐的写法：

```ts
function id(value: any): any {
  return value;
}

const result = id("hello");
// result 是 any，后续类型检查基本失效
```

泛型写法：

```ts
function id<T>(value: T): T {
  return value;
}

const str = id("hello"); // string
const num = id(123); // number
```

`T` 只是类型参数名称，可以写成 `Type`、`Value`、`Item` 等。

## 2. 显式指定泛型和自动推断

大多数时候 TypeScript 能根据参数自动推断：

```ts
const value = id(10); // number
```

也可以手动指定：

```ts
const value = id<number>(10);
```

手动指定常见于 TypeScript 无法从参数中推断，或你希望约束返回值时。

## 3. 多个泛型参数

```ts
function pair<T, K>(a: T, b: K): [T, K] {
  return [a, b];
}

const p = pair(1, "hello"); // [number, string]
```

泛型参数之间也可以产生关系：

```ts
function mapValue<T, R>(value: T, fn: (value: T) => R): R {
  return fn(value);
}

const len = mapValue("hello", (s) => s.length);
```

## 4. 泛型约束

如果泛型内部要访问某些属性，需要加约束：

```ts
interface HasLength {
  length: number;
}

function getLength<T extends HasLength>(value: T): number {
  return value.length;
}

getLength("abc");
getLength([1, 2, 3]);
getLength({ length: 10 });
// getLength(123); // 报错
```

`extends` 在泛型里不是“继承类”的意思，而是“必须能赋值给某个类型”。

## 5. 使用 keyof 约束属性名

黑马教程中的 `getProp` 是泛型常见用法：

```ts
function getProp<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = {
  name: "jack",
  age: 18
};

const age = getProp(user, "age"); // number
const name = getProp(user, "name"); // string
// getProp(user, "height"); // 报错
```

这里：

- `keyof T` 得到对象类型的所有键。
- `K extends keyof T` 限制 `key` 必须是对象已有键。
- `T[K]` 表示对应键的值类型。

## 6. 泛型接口

```ts
interface ApiResponse<T> {
  code: number;
  data: T;
  message: string;
}

type User = {
  id: string;
  name: string;
};

const response: ApiResponse<User> = {
  code: 0,
  data: {
    id: "u_001",
    name: "jack"
  },
  message: "ok"
};
```

数组接口也可以用泛型描述：

```ts
interface MyArray<T> {
  [index: number]: T;
}

const list: MyArray<number> = [1, 2, 3];
```

## 7. 泛型类

```ts
class Store<T> {
  private value: T;

  constructor(value: T) {
    this.value = value;
  }

  getValue(): T {
    return this.value;
  }

  setValue(value: T) {
    this.value = value;
  }
}

const stringStore = new Store("hello");
stringStore.setValue("world");
// stringStore.setValue(123); // 报错
```

泛型类的类型参数作用在实例侧，静态成员不能直接使用类的泛型参数：

```ts
class Box<T> {
  value!: T;

  // static defaultValue: T; // 报错
}
```

## 8. 泛型默认值

```ts
type Result<T = string> = {
  value: T;
};

const r1: Result = { value: "hello" };
const r2: Result<number> = { value: 1 };
```

函数也可以使用泛型默认值：

```ts
function createList<T = string>(): T[] {
  return [];
}
```

默认泛型只有在无法推断或没有显式指定时才会使用。

## 9. 泛型工具类型入门

教程中提到 `Partial`、`Readonly`、`Pick`、`Record`。这些都是 TypeScript 内置工具类型，本质上是泛型类型别名。

```ts
interface Props {
  id: string;
  title: string;
  children: number[];
}

type PartialProps = Partial<Props>;
type ReadonlyProps = Readonly<Props>;
type PickProps = Pick<Props, "id" | "title">;
type RecordObj = Record<"a" | "b" | "c", string[]>;
```

它们的大致含义：

- `Partial<T>`：把所有属性变成可选。
- `Readonly<T>`：把所有属性变成只读。
- `Pick<T, K>`：从类型中挑出部分属性。
- `Record<K, T>`：创建一组键为 `K`、值为 `T` 的对象类型。

更完整的工具类型在第 9 章说明。

## 10. 泛型命名建议

常见单字母：

- `T`：Type，普通类型参数。
- `K`：Key，键名。
- `V`：Value，值。
- `E`：Element，元素。
- `R`：Return，返回值。

业务代码中也可以用更明确的名称：

```ts
function createMap<Key extends string, Value>(entries: [Key, Value][]) {
  return Object.fromEntries(entries) as Record<Key, Value>;
}
```
