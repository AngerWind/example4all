# 对象、数组、元组与枚举

## 1. 对象类型

对象类型可以直接使用字面量结构描述：

```ts
let user: {
  name: string;
  age: number;
  sayHi(): void;
};

user = {
  name: "jack",
  age: 18,
  sayHi() {
    console.log("hi");
  }
};
```

属性之间可以用分号或换行分隔。对象值本身仍然用逗号分隔：

```ts
type User = {
  name: string;
  age: number;
};

const user: User = {
  name: "jack",
  age: 18
};
```

## 2. 可选属性

属性后加 `?` 表示可选：

```ts
type User = {
  name: string;
  age?: number;
};

const u1: User = { name: "jack" };
const u2: User = { name: "rose", age: 18 };
```

读取可选属性时，要考虑它可能是 `undefined`：

```ts
function printAge(user: User) {
  if (user.age !== undefined) {
    console.log(user.age.toFixed());
  }
}
```

## 3. 只读属性

`readonly` 表示属性只能在初始化或构造阶段赋值，不能在外部重新赋值：

```ts
type User = {
  readonly id: string;
  name: string;
};

const user: User = {
  id: "u_001",
  name: "jack"
};

// user.id = "u_002"; // 报错
user.name = "rose";
```

`readonly` 是 TypeScript 的类型约束，不等于运行时不可变。对象内部嵌套值如果是引用类型，仍可能被修改：

```ts
type State = {
  readonly list: string[];
};

const state: State = { list: [] };
state.list.push("todo"); // 可以
// state.list = []; // 不可以
```

## 4. 数组类型

数组常见两种写法：

```ts
let numbers: number[] = [1, 2, 3];
let names: Array<string> = ["a", "b"];
```

联合类型数组要加括号：

```ts
let values: (number | string)[] = [1, "a"];
```

只读数组：

```ts
const list: readonly number[] = [1, 2, 3];
// list.push(4); // 报错
```

也可以写成：

```ts
const list: ReadonlyArray<number> = [1, 2, 3];
```

## 5. 元组

元组是固定长度、固定位置类型的数组：

```ts
let point: [number, number] = [10, 20];
let user: [string, number] = ["jack", 18];
```

具名元组能提升可读性：

```ts
type UserEntry = [name: string, age: number];

const entry: UserEntry = ["jack", 18];
```

可选元素：

```ts
type Point3D = [x: number, y: number, z?: number];
```

## 6. 索引签名

当对象属性名不确定，但属性值类型确定时，可以使用索引签名：

```ts
interface NumberMap {
  [key: string]: number;
}

const scores: NumberMap = {
  math: 90,
  english: 88
};
```

注意：如果同时存在明确属性和字符串索引签名，明确属性的类型必须能赋值给索引签名的值类型：

```ts
type Bad = {
  name: string;
  // [key: string]: number; // name 的 string 不兼容 number
};

type Good = {
  name: string;
  [key: string]: string | number;
};
```

数组也可以理解为数字索引结构：

```ts
interface MyArray<T> {
  [index: number]: T;
}

const arr: MyArray<number> = [1, 2, 3];
```

## 7. 枚举

数字枚举默认从 `0` 开始：

```ts
enum Direction {
  Up,
  Down,
  Left,
  Right
}

Direction.Up; // 0
```

也可以手动指定值：

```ts
enum Direction {
  Up = 1,
  Down,
  Left,
  Right
}
```

字符串枚举必须给每个成员初始化：

```ts
enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT"
}
```

数字枚举具有反向映射特性——可以通过值反查键名：

```ts
enum Direction {
  Up,
  Down,
  Left,
  Right
}

Direction.Up;      // 0
Direction[0];      // "Up"
Direction["Up"];   // 0
```

编译后的 JavaScript 大致如下：

```js
var Direction;
(function (Direction) {
  Direction[Direction["Up"] = 0] = "Up";
  Direction[Direction["Down"] = 1] = "Down";
  // ...
})(Direction || (Direction = {}));
```

字符串枚举没有反向映射。这也是 `enum` 和 `as const` 对象的一个重要区别——`as const` 对象不会自动生成反向映射。

## 8. 枚举的取舍

普通 `enum` 会生成运行时代码：

```ts
enum Status {
  Active,
  Disabled
}
```

很多现代项目更偏向使用字面量联合类型或 `as const` 对象：

```ts
type Direction = "up" | "down" | "left" | "right";

const Direction = {
  Up: "up",
  Down: "down",
  Left: "left",
  Right: "right"
} as const;

type DirectionValue = (typeof Direction)[keyof typeof Direction];
```

如果需要运行时对象和类型都存在，`as const` 对象通常更灵活；如果维护的是已有 TS 项目，遇到 `enum` 也要能读懂。
