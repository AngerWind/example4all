# 高级类型与工具类型

## 1. typeof 类型操作符

JavaScript 中 `typeof` 返回运行时类型字符串：

```ts
console.log(typeof "Hello TS"); // "string"
```

TypeScript 中 `typeof` 也可以出现在类型位置，用于获取变量或属性的类型：

```ts
const point = { x: 1, y: 2 };

function formatPoint(value: typeof point) {
  console.log(value.x, value.y);
}

let x: typeof point.x; // number
```

也可以配合函数：

```ts
function add(a: number, b: number) {
  return a + b;
}

type AddFn = typeof add; // (a: number, b: number) => number
type AddReturn = ReturnType<typeof add>; // number
```

类型位置的 `typeof` 可以获取变量或属性的类型；函数名如果是一个值，也可以用 `typeof fn` 获取函数类型。但不能直接对任意函数调用表达式使用 `typeof add(1, 2)` 作为类型。

## 2. keyof

`keyof` 获取对象类型的所有键，并组成联合类型：

```ts
type Person = {
  name: string;
  age: number;
};

type Keys = keyof Person; // "name" | "age"
```

但是如果type中有字符串索引签名, 那么情况又会不一样
```ts
type A = {
    [key: string]: number
}
type k = keyof A // string | number
```
为什么会这样呢, 因为 keyof 本质上是获取一个类型所有key的联合签名
但是在索引签名中, key可以是任何的字符串, 所以使用 keyof 获取到的类型不是字符串字面量类型, 而是string类型

又因为在JS中, **object[1] 是 等价于 object["1"] 的**, 所以如果一个对象他所有的key都是string类型, 
那么key也可以是数字类型, 他们是等价的

所以在ts中规定: 如果存在 string 索引签名，那么 keyof 会包含 string，并额外包含 number（因为 number 会被隐式转成 string）

更完整的规则是:
1. 只有string 索引签名
   ```ts
   type A = { [key: string]: any };
   type K = keyof A; // string | number
   ```
2. 只有number索引签名
   ```ts
   type A = { [key: number]: any };
   type K = keyof A; // number
   ```
3. string索引签名 + 具体字段
   ```ts
   type A = { 
     name: string;
     [key: string]: any;
   };
   type K = keyof A; // string | number, 即使你写了 name，最终也会被“扩展”为 string key 的一部分。
   ```


## 3. 索引访问类型

索引访问类型用于获取属性值类型：

```ts
type Props = {
  a: number;
  b: string;
  c: boolean;
};

type A = Props["a"]; // number
type AB = Props["a" | "b"]; // number | string
type Values = Props[keyof Props]; // number | string | boolean
```

获取数组元素的类型：

```ts
const users = [
  { name: "Alice", age: 15 },
  { name: "Bob", age: 23 }
]; // users的类型是 {name: string, age: number}[]


/**
 * 这里是数组索引类型 (typeof users)[number];
 * (typeof users)[number] 表示从数组类型中获取元素的类型
 * 所以 (typeof users)[number] 的结果是 {name: string, age: number}
 */
type User = (typeof users)[number]; 
type Age = User["age"]; // 这里从 {name: string, age: number} 中获取age的类型
```

## 4. 映射类型

映射类型基于一组键创建新对象类型：

```ts
type Props = {
  a: number;
  b: string;
  c: boolean;
};

type ToBoolean<T> = {
  [K in keyof T]: boolean;
};

type BooleanProps = ToBoolean<Props>;
```

映射类型只能用于 `type`，不能直接写在 `interface` 中：

```ts
type Keys = "x" | "y";
type Point = {
  [K in Keys]: number;
};
```

## 5. 映射修饰符

构建一个一模一样的类型
```ts
type MyCopy<T> = {
  [K in keyof T]: T[K] // 把T中的每一个key拿出来, 构造成一个新的类型
}
```

构建一个key一样, 但是value不一样的类型
```ts
type MyCopy<T> = {
  [K in keyof T]: () => T[K] // key一样, 但是value变成一个函数
}
```

添加或移除可选：

```ts
type MyPartial<T> = {
  [K in keyof T]?: T[K]; // 所有属性都变成可选, ?表示属性可选修饰符
};

type MyRequired<T> = {
  [K in keyof T]-?: T[K]; // 所有属性必选, -?表示移除可选修饰符
};
```

添加或移除只读：

```ts
type MyReadonly<T> = {
  readonly [K in keyof T]: T[K]; // 所有属性readonly
};

type Mutable<T> = {
  -readonly [K in keyof T]: T[K]; // 所有属性非readonly, -readonly表示移除只读修饰符
};
```

## 6. key remapping

TypeScript 支持在映射类型的时候用 `as` 对获取到的key进行重命名, 过滤, 条件映射等：

即在mapped types的时候, 对key进行处理, 而不是直接映射

基本结构
```ts
  [K in keyof T as NewKey]: T[K]
```

1. 对key进行重命名
```ts
type Getters<T> = {
  // 这里先用 string & K 将K的类型缩窄为可操作字符串类型
  // 任何Capitalize 将 K 转换为首字母大写
  // 任何在K的签名添加get
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type User = {
  name: string;
  age: number;
};

type UserGetters = Getters<User>;
// {
//   getName: () => string;
//   getAge: () => number;
// }
```

2. 对key进行过滤
也可以过滤键：

```ts
type RemoveKeys<T> = {
    // as K extends "kind" | "id" ? never : K 表示
    // 如果K 符合 kind 或者 id, 那么返回never, 表示移除这个属性, 否则保留
    [K in keyof T as K extends "kind" | "id" ? never : K]: T[K];
};

type User = {
    kind: string;
    id: number;
    name: string;
    age: number;
};

type Result = RemoveKeys<User>;
// {
// name: string;
// age: number;
// }
```

3. 条件转换
```ts
type EventHandlers<T> = {
    // T[K] extends string ? `on${Capitalize<string & K>}Change` : never]: (value: T[K]) => void;
    // 这里的意思是, 先获取key, 然后T[K]获取value的类型
    // 如果value的类型是string, 那么将key转换为 onXXXChange, value的类型为(value: T[K]) => void
    // 否则的话, never表示删除这个key
  [K in keyof T as T[K] extends string ? `on${Capitalize<string & K>}Change` : never]: (value: T[K]) => void;
};

type State = {
    name: string;
    age: number;
};

type X = EventHandlers<State>;

// {
// onNameChange: (value: string) => void;
// }
```

## 7. 条件类型

条件类型形式：

```ts
type IsString<T> = T extends string ? true : false;

type A = IsString<string>; // true
type B = IsString<number>; // false
```

条件类型常用来根据输入类型生成不同结果：

```ts
// 这里表示, 如果T中有message属性, 那么获取message属性的类型, 否则返回never类型
type MessageOf<T> = T extends { message: unknown } ? T["message"] : never;

type Email = {
  message: string;
};

type EmailMessage = MessageOf<Email>; // string

type User = {
    name: string;
};
type X = MessageOf<User>; // never
```

## 8. infer

`infer` 用在条件类型里，用于推断某个局部类型变量：

```ts
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

function getUser() {
  return { name: "jack", age: 18 };
}

type User = MyReturnType<typeof getUser>;
```

数组元素类型：

```ts
type ElementType<T> = T extends Array<infer Item> ? Item : never;

type A = ElementType<string[]>; // string
```

## 9. 分布式条件类型

当条件类型作用在联合类型上时，会分发到每个成员：

```ts
type ToArray<T> = T extends any ? T[] : never;

type A = ToArray<string | number>; // string[] | number[]
```

如果不想分发，可以用元组包住：

```ts
type ToArrayNonDist<T> = [T] extends [any] ? T[] : never;

type B = ToArrayNonDist<string | number>; // (string | number)[]
```

## 10. 模板字面量类型

模板字面量类型可以基于字符串字面量组合新类型：

```ts
type Lang = "en" | "zh";
type Page = "home" | "user";

type LocaleKey = `${Lang}_${Page}`;
// "en_home" | "en_user" | "zh_home" | "zh_user"
```

常用于事件名、接口字段转换：

```ts
type ChangedEvent<T> = `${string & keyof T}Changed`;

type User = {
  name: string;
  age: number;
};

type UserEvent = ChangedEvent<User>; // "nameChanged" | "ageChanged"
```

## 11. 常用内置工具类型

对象转换：

```ts
type A = Partial<User>; // 创建一个新类型, 结构和User一样, 只是所有属性可选 
// 等价实现
type Partial<T> = {
    [K in keyof T]?: T[K];
};


type B = Required<User>; // B类型和User一样, 只是所有属性必选
// 等价实现
type Required<T> = {
    [K in keyof T]-?: T[K];
};


type C = Readonly<User>; // C类型和User一样, 只是所有属性变为readonly
// 等价实现
type Readonly<T> = {
    readonly [K in keyof T]: T[K];
};

type D = Pick<User, "name">; // 从T中挑选部分的key, 组成新的类型
// 等价是实现
type Pick<T, K extends keyof T> = {
    [P in K]: T[P];
};


type E = Omit<User, "age">; // 从T中移除部分的key, 组成新的类型
// 等价实现
type Omit<T, K extends keyof any> = {
    [P in keyof T as P extends K ? never : P]: T[P];
};


type F = Record<"a" | "b", number>; // 构建一个属性是a和b, 类型是number的类型
// 等价实现
type Record<K extends keyof any, T> = {
    [P in K]: T;
};
```

联合类型过滤：

```ts
// Exclude的本质实现是 type Exclude<T, U> = T extends U ? never : T;
// 作用是从T中删除掉U
type A = Exclude<"a" | "b" | "c", "a">; // "b" | "c"

// Extract的本质实现是type Extract<T, U> = T extends U ? T : never;
// 从T中保留U
type B = Extract<"a" | "b" | "c", "a" | "b">; // "a" | "b"

// NonNullable的本质实现是 type NonNullable<T> = T extends null | undefined ? never : T;
// 作用是去除null和undefined
type C = NonNullable<string | null | undefined>; // string
```

函数和构造函数：

```ts
// Parameters获取函数的参数类型, 并返回一个元组类型, 这个元组的类型就是函数参数的类型
type P = Parameters<(name: string, age: number) => void>; // [name: string, age: number]

// ReturnType获取函数的返回类型
type R = ReturnType<() => string>; // string

class Person {
  constructor(name: string) {}
}
// 获取构造函数的参数类型, 返回一个元组, 元组的类型就是构造函数参数的类型
type CP = ConstructorParameters<typeof Person>; // [name: string]

// 获取Person new出来的实例的类型
type I = InstanceType<typeof Person>; // Person
```

Promise：

```ts

// 获取Promise的泛型的类型, 会递归拆包
type A = Awaited<Promise<string>>; // string
type B = Awaited<Promise<Promise<number>>>; // number
```

字符串工具：

```ts
type A = Uppercase<"hello">; // "HELLO"
type B = Lowercase<"HELLO">; // "hello"
type C = Capitalize<"hello">; // "Hello"
type D = Uncapitalize<"Hello">; // "hello"
```
