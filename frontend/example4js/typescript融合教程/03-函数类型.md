# 函数类型

## 1. 给函数参数和返回值标注类型

函数类型最常见的写法是分别标注参数和返回值：

```ts
function add(num1: number, num2: number): number {
  return num1 + num2;
}
```

箭头函数同理：

```ts
const add = (num1: number, num2: number): number => {
  return num1 + num2;
};
```

如果返回值能被清楚推断，可以省略返回值类型：

```ts
const add = (num1: number, num2: number) => {
  return num1 + num2;
};
```

但公共 API、复杂函数、递归函数建议显式写返回值类型。

## 2. 整体描述函数类型

也可以直接描述变量的函数类型：

```ts
const add: (num1: number, num2: number) => number = (num1, num2) => {
  return num1 + num2;
};
```

这种写法常用于回调函数、函数属性：

```ts
type RequestCallback = (url: string, status: number) => void;

const onDone: RequestCallback = (url, status) => {
  console.log(url, status);
};
```

## 3. 可选参数

可选参数使用 `?`：

```ts
function request(url: string, query?: Record<string, string>) {
  console.log(url, query);
}

request("/api/users");
request("/api/users", { page: "1" });
```

可选参数必须放在必选参数后面：

```ts
function fn(a: string, b?: number) {}
```

## 4. 默认参数

默认参数是 JavaScript 语法，TypeScript 会根据默认值推断类型：

```ts
function createPage(page = 1, pageSize = 20) {
  return { page, pageSize };
}
```

也可以显式标注：

```ts
function createPage(page: number = 1, pageSize: number = 20) {
  return { page, pageSize };
}
```

默认参数不等同于可选参数，但调用时可以省略：

```ts
createPage();
createPage(2);
```

## 5. 剩余参数

剩余参数使用数组类型：

```ts
function sum(...numbers: number[]): number {
  return numbers.reduce((total, current) => total + current, 0);
}

sum(1, 2, 3);
```

如果参数数量和位置固定，可以使用元组：

```ts
function logPair(...pair: [string, number]) {
  const [name, age] = pair;
  console.log(name, age);
}
```

## 6. void 返回值

如果函数没有有意义的返回值，写 `void`：

```ts
function log(message: string): void {
  console.log(message);
}
```

注意：`void` 不表示函数一定没有 `return`，而是调用方不应该依赖它的返回值。

## 7. 函数重载

当一个函数根据不同参数返回不同类型时，可以使用函数重载：

```ts
function format(value: string): string;
function format(value: number): string;
function format(value: string | number): string {
  return String(value);
}

format("hello");
format(123);
```

重载签名只描述外部可调用方式；最后一个实现签名负责真实实现，并且必须兼容所有重载签名。

另一个更有价值的例子：

```ts
function getValue(key: "id"): number;
function getValue(key: "name"): string;
function getValue(key: "id" | "name") {
  return key === "id" ? 1 : "jack";
}

const id = getValue("id"); // number
const name = getValue("name"); // string
```

## 8. 函数兼容性

黑马教程中讲到“参数少的函数可以赋值给参数多的函数”：

```ts
type F1 = (a: number) => void;
type F2 = (a: number, b: number) => void;

let f1: F1 = (a) => {};
let f2: F2 = f1;
```

这是因为调用 `f2(1, 2)` 时，实际函数忽略第二个参数是安全的。反过来不安全：

```ts
let f3: F2 = (a, b) => {};
// let f4: F1 = f3; // 不安全
```

这个规则在数组遍历中很常见：

```ts
const arr = ["a", "b", "c"];

arr.forEach((item) => {});
arr.forEach((item, index) => {});
arr.forEach((item, index, array) => {});
```

## 9. 可调用对象

有些值既能作为函数调用，又有属性。可以用接口描述调用签名：

```ts
interface Counter {
  (step: number): number;
  count: number;
  reset(): void;
}

const counter = ((step: number) => {
  counter.count += step;
  return counter.count;
}) as Counter;

counter.count = 0;
counter.reset = () => {
  counter.count = 0;
};
```

如果一个类型既能普通调用，又能 `new` 调用，可以同时写调用签名和构造签名：

```ts
interface DateLikeFactory {
  (value?: string): string;
  new (value?: string): Date;
}
```
