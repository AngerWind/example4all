# 扩展 ESLint（Extend ESLint）

> 原文链接：https://eslint.org/docs/latest/extend/

本指南面向希望扩展 ESLint 功能的读者。

为了扩展 ESLint，建议你具备以下条件：

- 了解 JavaScript，因为 ESLint 是用 JavaScript 编写的。
- 对 Node.js 有一定了解，因为 ESLint 运行在 Node.js 之上。
- 能熟练使用命令行程序。

如果你符合以上条件，请继续阅读以开始。
